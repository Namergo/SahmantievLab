**Статус темы:** ждём утверждения

## О проекте

Учебная информационная система для отдела маркетинга ООО «Кинопоиск». Система позволяет создавать заявки на анализ рекламных кампаний, назначать аналитиков и отслеживать статус выполнения.

**Главный объект:** заявка на анализ рекламной кампании.
**Справочник:** рекламная кампания.
**Роли:** маркетолог (создаёт), руководитель аналитики (назначает), аналитик (меняет статус).

