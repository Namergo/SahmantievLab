## О проекте

Учебная информационная система для отдела маркетинга ООО «Кинопоиск». Система позволяет создавать заявки на анализ рекламных кампаний, назначать аналитиков и отслеживать статус выполнения.

**Главный объект:** заявка на анализ рекламной кампании.
**Справочник:** рекламная кампания.
**Роли:** маркетолог (создаёт), руководитель аналитики (назначает), аналитик (меняет статус).

## Запуск клиента (ЛР3)

```bash
cd frontend
npm install
npm run dev
```

Открыть адрес Vite, обычно http://localhost:5173.

## Запуск backend (ЛР7)

```bash
cd backend
dotnet restore
dotnet run
```

- API: http://localhost:5000
- Swagger: http://localhost:5000/swagger
- Health: http://localhost:5000/health
- Info: http://localhost:5000/info

**Ограничения ЛР7:**
- Данные заявок пока в памяти — после перезапуска пропадут.
- `/health` проверяет только доступность процесса (liveness), а не создание заявки.
- Настоящее создание заявки появится в ЛР8. Сейчас `POST /api/requests` не реализован.
