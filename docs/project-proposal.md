## 1. Название и организация

- Название системы: Заявки на анализ рекламной кампании
- Организация / подразделение: ООО «Кинопоиск», отдел маркетинга
- № из таблицы примеров: своя тема

## 2. Главная сущность и справочник

- Главный объект (одна запись процесса): заявка на анализ рекламной кампании
- Справочник (вторая таблица, ссылка числом): рекламная кампания
- Поле-ссылка (как назовёте в JSON/БД): `campaignId`

## 3. Роли и права

| Роль | Создаёт | Назначает | Меняет статус |
| :--- | :--- | :--- | :--- |
| Маркетолог | да | нет | нет |
| Руководитель аналитики | нет | да | нет |
| Аналитик | нет | нет | да |

Исполнитель не назначает себя, если этого нет отдельным требованием.

## 4. Сценарий в одно предложение

Маркетолог создаёт заявку на анализ рекламной кампании, руководитель аналитики назначает аналитика, аналитик меняет статус заявки.

## 6. Что не входит в семестр

1. Машинное обучение для анализа эффективности
2. Интеграция с рекламными площадками (Яндекс.Директ, Google Ads)
3. Дашборды и визуализация метрик
4. Автоматическая генерация отчётов
5. Мобильное приложение

## 7. Запас под ВКР

1. Данные/процесс: ML-анализ эффективности рекламы на основе исторических данных
2. Связи с другими системами: интеграция с API рекламных площадок для автоматического сбора метрик
3. Масштаб: мультиплатформенный анализ (несколько рекламных каналов одновременно)
4. Данные/процесс: предиктивная модель оценки ROI кампаний

## 8. Чем не копия соседа

Другой заказчик (ООО «Кинопоиск», не университет), другой главный объект (заявка на анализ рекламы, не бронь аудитории), другие роли (маркетолог и аналитик, не преподаватель и диспетчер).
