## Ответы на контрольные вопросы

- **Почему `400` не попадает в `catch`?** — `fetch` не считает HTTP-ответ ошибкой, пока он получен. `catch` срабатывает только при отсутствии ответа (сервер не запущен, неверный URL, обрыв сети). Поэтому проверяем `response.ok` и `status` вручную.
- **Чем `500` отличается от отсутствия сети?** — `500` — это ответ сервера с ошибкой, запрос дошёл. «Нет связи» — ответа нет вообще. Тексты для человека разные.
- **Откуда берутся `id` и `number`?** — Из ответа API (`{ id, number, status: 'New' }`). Форма их не вычисляет.
- **Зачем блокировать кнопку во время POST?** — Чтобы двойной клик не создал две записи. Флаг `isSubmitting` снимается в `finally`, поэтому после ошибки кнопка снова активна.
